Now focus on the model.  I want to completely change it.  Here's how I want the
model to work:

* An input layer of neurons, of shape [n_input, 2].  There are two kinds of input neurons:
- Neurons who's rate is the input stimulus
- Neurons who's rate is 1 minus the input stimulus

* One hidden layer of neurons, of shape [n_input, n_channels].  I want local
convolution weights from the inputs and local convolutional recurrent weights
from hiddens to hiddens.

More details:

Inputs to hiddens:
- Initialised randomly in [0, 1]
- At every step, the output weights from each input neuron are non-negative and
scaled to sum to a hyperparameter.
- At every step, the input -> hidden weights are multiplicatively scaled in
proportion to the correlation of the pre-synaptic and post-synaptic unit.  Each
unit maintains a running estimate of its mean firing rate so these correlations
can be computed.

Recurrent connections:
- Same as inputs to hiddens (initialized randomly, nonnegative, modified by
correlation), but with a different normalization hyperparameter.

Hidden activity:
- h(t+1) = tau * h(t) + (1 - tau) * sigmoid(W_in * I + W_h * h)

Implement this model and write a demo script to plot the input and hidden
activities over time for the drift task, both before and after training.

Note that there's no gradients here, so no need for pytorch.  You can do

A couple changes:

* I want the Hebbian learning rule to be additive, not multiplicative.  Namely,
